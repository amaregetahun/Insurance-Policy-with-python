             Insurance Policy Categorizer

A lightweight Python script that classifies insurance policies based on their unique policy identification numbers using optimal conditional logic and operational operators.

     Features

1. Direct Operational Evaluation: Uses highly efficient relational operators (==) for explicit value matching.
2. Conditional Branching: Implements standard if-elif-else control flow structures to minimize processing overhead.
3. User-Interactive Input: Features execution-time dynamic input handling via the standard console terminal.
